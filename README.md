# 🧾 电子发票自动拼版与粘贴单合并工具 (Invoice Auto Merger)

这是一个基于 Python 的轻量级办公自动化工具，专为解决财务报销中繁琐的发票打印问题而生。

它可以自动将**横向的电子发票**按“一页两张”的格式完美拼版到**竖向 A4 纸**上，并在每页拼好的发票后**自动插入一页指定的报销粘贴单**。

🔥 **全新升级**：采用“强制高清图片化（Flatten）”技术，彻底解决带有电子签名或复杂图层的电子发票在打印时出现的黑块、文字丢失等兼容性问题，让你告别手动排版的折磨，实现一键无忧生成报销文件！

🆕 **按类目分组**：支持将发票按粘贴单背面表格的费用类目分别放入子文件夹，程序会确保**每张粘贴单背后只贴同一类发票**，直接满足财务"按项目用途分类"的硬性要求。

🆕 **自动填写张数和金额**：每张粘贴单背面的"个人填写"区会自动填好这张粘贴单**对应的那 1~2 张发票**的张数、金额和合计——金额从发票 PDF 文本里提取（价税合计/小写），完全无需手填。

🆕 **运行时输入姓名**：跑 notebook 时会提示输入姓名，自动写到每张粘贴单的右下角；姓名不会写入代码或配置文件，repo 可以放心公开。

## ✨ 核心功能

* **📸 高清图片化防错 (Flatten)**：底层强制将发票转换为 3 倍超高清图片后再进行拼版，完美保留二维码和微小数字，100% 杜绝因 PDF 矢量图层、特殊字体或电子签章引起的打印机报错。
* **🤖 智能缩放排版**：无视原发票内部复杂的旋转或坐标属性，利用 PyMuPDF 强制将两张横向发票等比缩小（70.7%）并精准上下对齐到竖向 A4 纸中。
* **🗂️ 按类目分组装订**：每个类目独立装订（每类发票 + 该类自己的粘贴单），类与类之间不会混页。某类只有奇数张时，最后一页下半张留白而非被下一类填满。
* **🧮 自动张数 + 金额合计**：每张粘贴单上只统计它后面那一张或两张发票，张数（1 或 2）、金额合计、合计行一并填到"个人填写"列，金额提取失败的发票会打印警告并把该粘贴单的金额栏留空让你手填。
* **✍️ 自动签名**：运行时输入姓名一次，所有粘贴单右下角自动写好（用 Windows 自带黑体/宋体/雅黑），回车跳过则不写。
* **📑 自动穿插粘贴单**：每个类目的发票拼版后，程序会自动追加一页《报销粘贴单》图片，排版顺序与粘贴单背面表格自上而下完全对应。
* **📁 规范的目录管理**：发票源文件与粘贴单模板分文件夹独立存放，输出文件不会污染原文件夹。

## 📂 项目结构说明

在使用本工具前，请确保你的文件夹结构如下：

```text
invoice-auto-merger/
  ├── fapiao_process.ipynb     # 核心运行代码 (Jupyter Notebook 格式)
  ├── 待报销的发票/            # 👈 按类目分别放入对应子文件夹
  │    ├── 市内交通费/
  │    ├── 市外差旅费/         # 👈 此目录下再按子类型细分
  │    │    ├── 机票/
  │    │    ├── 火车票/
  │    │    ├── 打车/
  │    │    ├── 住宿/
  │    │    └── 餐饮/
  │    ├── 招待费/
  │    ├── 办公用品费/
  │    └── ……（共 25 个类目，按需使用，空文件夹会自动跳过）
  └── 粘贴单/
       └── 原始票据（_影像化）报销粘贴单.pdf  # 👈 你的空白粘贴单模板
```

完整的 25 个子文件夹名（与粘贴单背面表格一一对应）：

```
市内交通费、市外差旅费、国际合作交流费、办公用品费、图书资料费、
复印打印费、印刷费、版面费、水费办公、电费办公、邮寄费、电话费、
会议费、培训费、招待费、维修费、汽油费、材料费、家具设备费、专利费、
会员费、加班工作餐费、活动费、市政交通一卡通费、其它费用
```

其中 **市外差旅费** 下还要按子类型细分到以下 5 个子文件夹（各自独立装订，一张粘贴单背后只贴同一子类型）：

```
机票、火车票、打车、住宿、餐饮
```

> 💡 为了让 Windows 文件夹名干净好用，已去掉粘贴单上的全角括号和顿号——例如 `水费办公` 对应"水费（办公）"，`招待费` 对应"招待费（餐费、住宿费）"，`家具设备费` 对应"家具、设备费"。代码里的 `CATEGORIES` 列表是规范来源，要改名请同步修改。
>
> ⚠️ 直接放在 `市外差旅费/` 下（没进子类型文件夹）的 PDF 会被警告并跳过，必须放进 `机票`/`火车票`/`打车`/`住宿`/`餐饮` 之一。

## 🛠️ 环境依赖与安装

本项目依赖 `PyMuPDF` 处理 PDF 文件。请在你的命令行或终端中运行以下命令安装必备库：

```bash
pip install PyMuPDF
```

## 🚀 如何使用

1. **分类准备发票**：把每张 PDF 电子发票放入 `待报销的发票` 下对应的类目子文件夹。
   * 直接放在 `待报销的发票` 根目录下的 PDF 会被警告并跳过。
   * 不在类目清单里的子文件夹也会被警告并跳过。
2. **准备模板**：确认 `粘贴单` 文件夹中存在名为 `原始票据（_影像化）报销粘贴单.pdf` 的文件（如需更改名字，请在代码中同步修改路径）。
3. **运行代码**：
   * 打开 `fapiao_process.ipynb`。
   * 运行全部代码块。
4. **获取结果**：运行完成后，项目主目录下会自动生成一个名为 **`最终_全部图片化_发票带粘贴单.pdf`** 的文件，直接拿去打印机双面/单面打印即可！
